# Security Policy

## Reporting a vulnerability

Report a security vulnerability privately through
[GitHub's private vulnerability reporting](https://github.com/allodops/chronoduck/security/advisories/new)
for this repository, rather than filing a public issue.

Include what you'd include in a bug report: what you observed, what you expected, the version or
commit affected, and a reproduction if you have one.

## Response

You can expect an initial response within 14 days. If the report is confirmed, a fix will be
prepared and coordinated disclosure discussed before any public advisory.

## Scope

This policy covers the ChronoDuck extension code in this repository. It does not cover DuckDB
itself (the `duckdb` submodule) — report those upstream to
[duckdb/duckdb](https://github.com/duckdb/duckdb/security).
