# Support

## Usage questions

Open a [GitHub issue](https://github.com/allodops/chronoduck/issues/new/choose) using the
`Question` label, or start a
[GitHub Discussion](https://github.com/allodops/chronoduck/discussions) if discussions are enabled
for this repository.

## Bugs and feature requests

See `CONTRIBUTING.md` for how to file a bug report or propose a change — use the issue forms under
"New issue" rather than a blank issue, since they collect what a reviewer actually needs.

## Security issues

Do not use a public issue for a security vulnerability — see `SECURITY.md`.
