# Primitives

One hundred and fifteen registry rows are composed from about seventy primitives in nine tiers (0–8). The ratio is the point: `rate`, `increase`, `resets`, `hist_rate` and `hist_increase` are all `counter_fold` + `extrapolate` with different plugs. Each primitive is its own translation unit, with its own tests (`docs/testing/`).

| Tier                 | Primitives                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                     | Serves                                                                                                                                      |
|----------------------|------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|-----------------------------------------------------------------------------------------------------------------------------------------------|
| 0 · numeric          | `kahan_add`, `kahan_merge` (Neumaier, FMA-defeating, Inf-safe); `reproducible_sum` (order-independent, for the D0 sum path); `almost_equal` (the comparator); `is_stale`, `stale_marker`; `linear_regression` (origin-shifted least squares); `quantile_linear`                                                                                                                                                                                                                                                                                                                                                                                                                                                                                | every sum and mean; deriv, predict_linear; quantile, mad                                                                                    |
| 1 · time and grid    | `Grid{start,end,step}` with `count / at / index_of`; `Window.contains` — the single home of `anchor − width < t ≤ anchor`; `lookback_bound` and the `carry` rule; `scan_bounds(grid, window, lookback, mode)`                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                  | every function; the scan-bound pushdown                                                                                                     |
| 2 · sample buffers   | `Sample{t,v}`, `HistSample{t,h}`; `SampleBuffer` (arena-backed; `append / merge / sort_dedup / slice`); `dedup_policy` (keep-greatest under IEEE `totalOrder`, NaN loses to non-NaN, stale loses to NaN; histograms by `(count, compact-then-xxh3)`); `LastK<n>`; `SlicePartials` with `Count / Sum / MinMax / First / Last` partials                                                                                                                                                                                                                                                                                                                                                                                                          | the RAW_WINDOW, LAST_K and SLICE states                                                                                                     |
| 3 · window iteration | `window_walk` (two monotone pointers, O(n + steps)); `grid_stream` (the operator's per-partition walk: same pointers over the partition's sorted stream, one window resident, buffers released at each series boundary); `edge_context` (the last sample at or before `t − w` — which `Window.contains` excludes — and the first after `t`); `slice_walk`                                                                                                                                                                                                                                                                                                                                                                                      | every RAW_WINDOW finalize; ANCHOR and SMOOTH; SLICE functions                                                                               |
| 4 · fold kernels     | `counter_fold` (first, last, n, reset-adjusted delta, resets, with the reset predicate as a plug); `extrapolate` (the reference's classic edge arithmetic, `EXTRAPOLATE` only, as a pure function of the fold summary: threshold = 1.1 × the average inter-sample interval; a boundary gap under threshold extrapolates all the way to the boundary, over threshold falls back to half the average interval; for `COUNTER` inputs, a zero clamp keeps the left-edge extrapolation from implying a negative counter value; a start timestamp strictly inside the left gap short-circuits that side to zero duration, which is what lets a single sample yield a rate); `extended_fold(left, right, inside)` (the `ANCHOR`/`SMOOTH` fold: anchor at the last sample at or before `t − w`, edges interpolated with reset-to-zero, reset correction — the same `value drop ∨ st_reset` predicate `counter_fold` uses, a deliberate divergence from the reference's extended-range `extendedRate`, whose reset correction is value-drop only — as a loop over the inside sequence seeded with `left` and closed with `right`, no threshold, no clamp, divided by the nominal window width, not the real elapsed time between `left` and `right` (ADR 0017) — a different fold, not a variant); `instant_pair`; `changes_fold` (NaN–NaN carve-out); `reduce_fold<Op>`; `moments_fold` (two-pass); `holt_winters_fold`; `carry_fold` | rate, increase, delta, resets, hist_rate…; irate, idelta; changes; the \*\_over_time family; stddev, stdvar; double_exp_smoothing; resample |
| 5 · histograms       | `Hist` struct; `hist_monotone_repair` (the reference's cumulative-count repair with its small-delta threshold, for classic buckets that are rate outputs); `bucket_index / lower_bound` (2^(2^−scale), upper-inclusive, the OTel/Prometheus off-by-one pinned); `hist_downscale`; `hist_add / hist_sub` (downscale to min scale, reconcile zero thresholds, bucket-wise); `hist_compact`; `hist_detect_reset`; `hist_quantile`, `hist_fraction`, `hist_moments`; `hist_from_values`, `hist_from_classic`                                                                                                                                                                                                                                                                                                                                                                                   | the whole hist\_\* family                                                                                                                   |
| 7 · series numerics  | `series_view` (LIST + descriptor, NULL cells); fills (`forward / backward / linear / const / spline` with the tridiagonal solve); `fir_convolve`; `iir_recurrence` (EMA, exponential smoothing and cumsum are its special cases); `time_decay_kernel`; `fft_radix2`, `bluestein`, `twiddle_table`; `acf`, `ccf`, `period_search`; `loess`, `stl_loop`, `additive_decompose`, `holt_winters_seasonal`; `polyfit_chebyshev`, `huber_irls`, `two_line_split`; `tukey_fence`; `znorm`; `lttb_buckets`, `asap_search`; `paa`, `sax_breakpoints`; `dtw_dp` with band, `lb_keogh`; `stomp_recurrence`; `pelt`, `bocpd`; `ks_statistic`, `ks_pvalue`                                                                                                       |
| 8 · pattern engine   | `pattern_parser` (the SQL:2016 §R grammar, a Tier primitive with its own fence — the one embedded mini-language the constitution admits); `pattern_compiler` (Glushkov NFA); `match_buffer` with `WITHIN` pruning; `selection_policy` (the SASE policies mapped onto AFTER MATCH SKIP); `measures_eval`                                                                                                                                                                                                                                                                                                                             |
