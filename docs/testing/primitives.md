# Testing the primitives

The primitives are listed in `docs/design/primitives.md`. Testing attaches to them first, because a
kill test on `extrapolate`'s threshold defends five registry rows at once and a bug found only
through `rate` cannot be attributed. Each primitive is a translation unit with a `_test.cpp`, a
mutation leg of its own, and an entry in the citation index. The tables give the unit contract, the
invariant the property sweep checks, the oracle that exists *independently of any registry
function*, and the mutants that must die.

## Integration seams (L1c)

Where a contract crosses from one tier to the next, a seam test drives the pair with a sentinel that
only the correct hand-off preserves. The seams are a closed roster; each is named after the
contract, not the files.

| Seam                                | Contract                                                                                                                                                                                                             | Sentinel test                                                                                                                                                                                                                                                                                                                                                                        |
|--------------------------------------|--------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| buffer → window_walk                | The walk sees a sorted, deduplicated buffer and never mutates it                                                                                                                                                     | Walk an unsorted buffer: must fail an assertion, never return; hash the buffer before and after a walk                                                                                                                                                                                                                                                                               |
| window_walk → fold                  | The fold receives a view `[lo, hi)` plus edge context and touches nothing outside                                                                                                                                    | Poison the samples outside every view (NaN with a distinct payload) and assert no output carries the payload                                                                                                                                                                                                                                                                         |
| counter_fold → extrapolate          | Under `EXTRAPOLATE` only: extrapolate reads the fold summary, never the samples. `extended_fold` is exempt by construction — it consumes the inside sequence — and has its own tables transcribed from the reference | Pass a summary with a deliberately inconsistent sample buffer; output must depend only on the summary                                                                                                                                                                                                                                                                                |
| SlicePartials → slice_walk → reduce | Bucket partials are complete and disjoint before any walk                                                                                                                                                            | Merge partials in every order of a 3-partition and assert the walk's output is bit-identical                                                                                                                                                                                                                                                                                         |
| state → host combine                | Combine never calls finalize; the source is unchanged unless destructive was declared                                                                                                                                | Instrument finalize with a call counter; assert zero calls during combine; hash the source                                                                                                                                                                                                                                                                                           |
| fold → finalize_to_list             | One output per grid point, in grid order, NULL where the fold returned nothing                                                                                                                                       | A fold that returns a value only at odd grid points; assert the NULL mask is the exact complement                                                                                                                                                                                                                                                                                    |
| Hist struct ↔ DuckDB STRUCT vector  | Round-trip through the vector layout preserves every field including sparse spans and custom bounds                                                                                                                  | Upstream histogram tables serialised, deserialised and compared with `Equals` after compact                                                                                                                                                                                                                                                                                          |
| bind → scan_bounds → rows scanned   | The bound derived at bind is the one the scan applies                                                                                                                                                                | Two gates, because pruning is at row-group granularity: the pushed predicate appears on the `Get` in the profiling JSON, and `rows_scanned ≤ samples_in_bound + G × runs` for the fixture's row-group size `G`; a sentinel asserts that removing the bound multiplies rows scanned by ≥ 10×. The JSON keys read are pinned in the lane registry, since they changed between releases |

Each primitive's mutation leg is scoped to its own translation unit with L1a as the runner, so a
survivor is attributed to a primitive and a construct, never to "the kernel". The registry-level
mutation leg (L10) then runs with L1b–L5 as the runner and must add nothing new: a mutant killed at
L10 but not at L1a means a primitive test is missing, and the L13 meta-test compares the two kill
sets and fails on that difference.
