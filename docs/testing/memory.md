# Memory and scale

Each state class declares its size law (the SKETCH, SERIES and NFA laws are in the Surface extension's addenda) — `RAW_WINDOW` is `O(samples in [start − window − lookback, end])` per series; `SLICE` is `O(steps)`; `LAST_K` is constant — and a test measures the actual allocation against it with a stated constant factor. A 1 M-sample single-series run asserts the RSS delta under a ceiling that would be violated by any implementation that copies the buffer on combine rather than moving it. There is no spill test, because there is nothing to spill: the tracked allocator accounts for state heap, it does not move it to disk, and a test written to "prove spill" would have been a fake sentinel. Instead the operator path is measured on a 30-day, 1 s-resolution, 10 k-series query with a 5-minute window — window ≪ range, or the query proves the wrong law — and its resident state held to `threads × window × c` with a stated constant: *not* `series × window`, which is loose enough to accept the exact retention leak the sentinel exists to catch. Three memory numbers are reported and only the first is the law: tracked-allocator state bytes, DuckDB's peak buffer memory (the partition sort and the scan), and process peak RSS from `/proc` as a ceiling, one shape per process because the allocator retains freed pages. Serialised `_state` size per state class is a fourth sentinel, since a `RAW_WINDOW` state written to a downsampling table is O(range) per row. The aggregate form is measured on the same query and its O(range) cost recorded in the docs as the reason it is not the default. The scan-bound rule from cerberus applies in its DuckDB form: the time predicate pushed to the scan is asserted from `EXPLAIN ANALYZE`'s rows-scanned counter, because removing it produces identical output.

A self-check lane breaks each bounding mechanism on purpose — removes the scan bound, replaces the move with a copy, disables the arena, retains every series' window buffer until pipeline end instead of releasing at the series boundary, serialises the whole buffer into `_state` instead of the window — and asserts the corresponding sentinel goes red. A sentinel that stays green when its mechanism is gone is not a sentinel.
