# Deliberate fixtures

Cerberus's seeds annotate each shape with the query behaviour it discriminates. The kernel's fixture families do the same, and the registry requires every function to name which families apply. A family absent from a function's L1 tables is an L13 failure.

| Family    | Shape                                                                                                                                                                                      | What it discriminates                                                                                                      |
|-----------|------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|-------------------------------------------------------------------------------------------------------------------------|
| reset     | Counter with one reset mid-window; with a reset on the first sample; with two consecutive resets                                                                                          | Reset accumulation, the zero clamp in extrapolation, `resets` counting                                                     |
| dup       | Same timestamp, same value; different values; `−0.0` vs `+0.0`; NaN vs value; two NaN payloads; stale vs NaN; two histograms with equal `count` (all resolved by the declared total order) | The 50-vs-37.5 bug: sample count inflating the interval estimate; the declared tie-break                                   |
| edge      | Sample at exactly `t − range`; at exactly `t`; at `t − range + 1µs`; grid point between two samples with equal gaps                                                                       | Left-open/right-closed rule; microsecond-vs-millisecond alignment                                                          |
| threshold | Gap to an edge just under and just over `1.1 × avgInterval`; two samples only; single sample without a start timestamp; single sample with its start timestamp inside the window          | Half-interval extrapolation branch; the two-sample floor; NULL for one sample *only* when no start-timestamp role is bound |
| start-ts  | Start timestamp moved with no value drop; start timestamp equal to the previous sample's time; delta-temporality series                                                                   | The `st_reset` half of the reset predicate; a fixture family that cannot be written in a `(t, v)` grammar                  |
| clamp     | Counter whose extrapolated line would cross zero                                                                                                                                           | `durationToZero` clamp                                                                                                     |
| stale     | Stale-marker NaN at `t`; gap of `lookback − 1s`; gap of `lookback + 1s`; a 12-minute blackout inside a 1-hour grid                                                                         | Marker semantics vs ordinary NaN; carry vs NULL on resample                                                                |
| nan       | Ordinary NaN as first sample, last sample, and a two-sample NaN–NaN run                                                                                                                    | Prometheus's `changes()` NaN-both-sides carve-out; NaN propagation in sums                                                 |
| inf-sub   | ±Inf values; subnormal values; values near `DBL_MAX`                                                                                                                                       | Inf preservation in Kahan; no overflow in extrapolation factor; bucket mapping at the extremes                             |
| cadence   | Scrape 15/30/60 s against steps that are and are not multiples; window smaller than scrape interval; window equal to step                                                                 | Grid-anchor and alignment bugs; empty windows on sparse cadence                                                            |
| sweep     | Eval instant offsets `{0,15,30,60,90,120,180,300}s` off the sample clock, the last pushing the window off the data                                                                        | Anchoring to the wrong clock; both sides agreeing on empty                                                                 |
| order     | Rows shuffled; rows reversed; rows arriving in partials of one                                                                                                                             | Sort-in-finalize; combine assumptions about order                                                                          |
| anchor    | One sample before the window at various gaps; none before the window                                                                                                                      | Anchored and smoothed modes' dependency on the pre-window sample; classic's independence from it                          |
| hist      | Scale mix `{−1,0,1,2}` across series; a sparse instance dragging the merged schema down; custom-bucket (schema −53) histograms; zero-threshold widening                                   | Merge at coarsest schema; observable quantile movement; zero-bucket reconciliation                                         |
| scale     | 1 M samples in one series; 100 k series of ten samples                                                                                                                                     | State bytes, RSS ceiling, spill, fan factor                                                                                |

Every fixture carries both answers where a known bug exists — the correct value and the specific wrong value the bug produces — derived in a comment. A fixture that only says "expected 50" cannot tell a reviewer why 37.5 is the number a broken implementation returns; cerberus's `rate_dup_timestamp_test.go` is the model.
