# Benchmark lanes

Performance has the same two-tier posture as correctness: structural quantities gate, timings inform. No test fails on timing drift, and the one lane that deliberately breaks things is the one that proves the sentinels are real.

| Lane        | Posture     | Measures                                                                                                                                                                                                                                                                      | Gate                                                                                                                                                                                                                                                                                                                                                         | Informational                                                                                              |
|-------------|-------------|-------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|--------------------------------------------------------------------------------------------------------------|
