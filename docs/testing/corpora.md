The derivation tools are consumer-side projects and carry their own, smaller test discipline: they must be deterministic (same upstream input → byte-identical fixtures), must record the upstream version in every provenance field, and must emit a fixture for every single-function eval they can isolate, with a count the kernel-side sync test compares against. A derivation tool that silently drops evals it cannot parse would shrink the kernel's corpus without anything going red.
