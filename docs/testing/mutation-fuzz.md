# Mutation and fuzz

Mull runs over the kernel translation units only — state, combine, finalize, the extrapolation and reset code, the histogram merge — with L1, L3 (unit mode), L4 and L5 as the runner. The scoring rule is cerberus's in spirit, simplified by the tool: Mull runs a pre-instrumented binary, so there is no per-mutant compile to leash, and its statuses are `Passed`, `Failed` and `Timedout` — a test-binary watchdog that exits non-zero is recorded as `Failed`, indistinguishable from a kill, so the wrapper that records which clock fired is necessary, not optional. `efficacy = (killed + watchdog) / (killed + lived + runnerTimedOut + watchdog)`, with the runner's own timeout in the denominator only, a closed status set, and a per-mutant budget measured per run. The floor is 95 % per *tier* (Tier 0 numeric, Tier 1 grid, and so on), not per translation unit: a primitive like `Window.contains` has a dozen mutants, at least one of them equivalent because timestamps are deduplicated before it runs, and a per-TU floor would fail it forever. Two mutator classes carry a stricter rule: relational-operator mutants in reset detection, window-edge comparisons and the `1.1×` threshold must all be killed, and the meta-test that enforces it lists those functions by construct citation.

Survivors follow the ordered remedies — prove equivalent with a `NOT KILLABLE` footer citing the construct; else add a kill test that drives the public surface and asserts both sides of the guard; never refactor production code for the tool. Documented equivalents stay under 5 % of the tier's mutant total, or under an absolute two on any unit with fewer than forty mutants. Mull reports a single timeout status, so the watchdog-versus-backstop distinction the scoring rule needs is implemented by a wrapper that runs the test binary under its own timeout and records which clock fired.

Fuzzing has two halves. The SQL surface is fuzzed nightly by `fuzz_all_functions` with the extension loaded and every crash reduced by `reduce_sql_statement` and filed. The kernel is fuzzed structurally: a protobuf `Series` message carrying samples (timestamp, value, is_reset, is_nan flags), grid, window, mode and `split_points`, mutated by libprotobuf-mutator, executed once whole and once partitioned at the split points, asserting the full MR roster. Every L1 and L3 fixture is a seed. Crashes go to ASan; MR violations are property failures with a minimised repro that becomes an L1 table row.
